# Context7 MCP — Documentation Fetcher

# Cấu hình đầy đủ để dùng trong mcpServers:
# context7:
#   command: npx
#   args: ["-y", "@upstash/context7-mcp"]
#   transport: stdio
#   env:
#     CONTEXT7_API_KEY: "your-api-key-here"

## Capabilities
- Fetch tài liệu thư viện mới nhất (không bị hallucination)
- Tìm kiếm code examples từ docs chính thức
- Hỗ trợ 1000+ thư viện phổ biến

## Khi nào dùng
- Hỏi về API của thư viện (Flutter, FastAPI, React...)
- Tìm ví dụ code chính xác từ docs mới nhất
- Kiểm tra breaking changes giữa các phiên bản
