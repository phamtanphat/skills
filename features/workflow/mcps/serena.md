## Capabilities
- Symbol search và navigation trong codebase
- Code refactoring (rename, move)
- Find references và implementations
- Diagnostics và linting
- Memory/context management

## Khi nào dùng
- Tìm kiếm symbol trong dự án lớn
- Refactor an toàn (rename function/class)
- Hiểu cấu trúc codebase mới
- Debug bằng cách trace call chain
