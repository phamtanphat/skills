# Task Management — Quy trình quản lý công việc

## Quy tắc làm việc với AI
- Mô tả rõ context và yêu cầu trước khi bắt đầu
- Chia nhỏ task lớn thành subtasks cụ thể
- Review output của AI trước khi apply
- Không commit code chưa hiểu

## Definition of Done
- [ ] Code pass tất cả tests
- [ ] Code đã được review
- [ ] Documentation cập nhật nếu cần
- [ ] Deploy thành công lên staging
- [ ] Không có linting error

## Estimation
- `XS` — < 2 giờ
- `S` — 2-4 giờ
- `M` — 4-8 giờ (1 ngày)
- `L` — 2-3 ngày
- `XL` — > 3 ngày (cần tách nhỏ)
